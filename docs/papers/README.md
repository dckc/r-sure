# Papers

Third-party background used by the primer. Papers are archived for citation and are not
relicensed with the repository.

| File | Citation | Use |
|---|---|---|
| `NAIC_CIPR_2C_20July_2016.pdf` | Daniel R. Robles, "Insurance: The Highest and Best Use Case for Blockchain Technology," NAIC CIPR Newsletter, July 2016, pp. 17–27 | design philosophy, insurability questions, oracle rationale |

`manifest.json` records the SHA-256 of each file. `extracts/robles2016naic.md` contains the
page-level quotations used in the primer. The article is an opinion column: its views are
the author's and are not an official NAIC position.

The PDF's text layer drops some ligatures (for example "identifying" renders as "iden fying").
Quotations in the extract are reconstructed to standard spelling and marked as such.
