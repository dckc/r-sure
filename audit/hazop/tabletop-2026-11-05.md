## Purpose

Review the r-sure contracts for concurrency and composition deviations before attempting a
devnet campaign, and decide which P0/P1 findings to fix in this pass. The tabletop covers the
15 nodes in `nodes.yaml` and the interface matrix in `../composition/interfaces.yaml`.

## Decisions and deviations

### D-01 — `LOST` on a state cell in the cornerstone arms (N05, N08, N10, N11, N12)

**Deviation.** The arm takes a state cell, awaits an external component, then takes the same
cell again. The first snapshot is never reposted, so the second receive has no datum.

**Evidence.** `Syndicate@"openLine"` (`10_syndicate.rho:811`/`:868`), `Slip@"bind"`
(`13_slip.rho:427`/`:484`), `Policy@"distribute"` (`17_policy.rho:191`/`:242`),
`Policy@"openClaim"` (`:293`/`:315`), `Policy@"settleClaim"` (`:346`/`:391`,`:433`),
`Claim@"settle"` (`18_claim.rho:390`/`:404`), `Claim@"dispute"` (`:322`/`:361`),
`Distribution@"run"` (`15_distribution.rho:345`/`:360`).

**Decision.** Fix P0 in this pass. Use the original snapshot and repost once after the
awaits; do not add a second take. Record F-001, hazards HZ-001…HZ-005/HZ-025.

**Status.** Fixed in source; scanner `tools/check_take_repost.py` reports zero for the watched
arms. Regression suites remain `not_run`.

### D-02 — `PART OF` a bundle (N01, N05, N09, N11, N12, N15)

**Deviation.** Nine per-object contracts are published with `bundle+{*X}` while `X`'s body
references a state cell or token created outside `X`. The node rejects the bundle.

**Evidence.** Scanner `tools/check_bundle_closedness.py` reports `LineGrant`, `Syndicate`,
`Line`, `Slip`, `Policy`, `Claim`, `Distribution`, `Broker`, `Risk`.

**Decision.** Keep as a confirmed P0, open. The proposed fix is a closed publication/init
pattern: the bundled content must not capture the state cell or the purse/token; if data
capture is the cause, initialize it through an `init` arm. Do not claim install success until
`make install` completes. Record F-002, hazards HZ-006/HZ-007, improvement R-002.

**Status.** Open. The devnet was unavailable during this pass, so the unbundling experiment
was reverted rather than left unverified.

### D-03 — `NO/NOT` on global pause (N02)

**Deviation.** `pauseAll` writes `adminState.pausedAll`; no mutating arm consults `isPaused`.

**Decision.** Record F-003/HZ-008. Proposed fix R-003 wires a pause check into mutating arms
and explicitly exempts settlement, close, expiry and refund. Not fixed in this pass because
the change touches most components and needs a decision on which arms are "mutating" versus
"recovery".

**Status.** Open.

### D-04 — `REVERSE`/`STALE` on the fund nonce (N13)

**Deviation.** `SureFund.cover` writes `nonce`; `admin` uses `govNonce`; cover has no
`govNonce` replay check.

**Decision.** Fix: `fundAdmin` rejects `nonce <= govNonce`; cover writes `govNonce`. Record
F-004/HZ-009.

**Status.** Fixed in source; regression not run.

### D-05 — `UNAUTHORIZED` on broker registration (N06)

**Deviation.** `BrokerBook.registerDone` is a public arm accepting an arbitrary id/uri.

**Decision.** Fix: remove the public callback and update `brokerBookState` directly inside
`brokerMake`. Record F-008/HZ-013.

**Status.** Fixed in source; regression not run.

### D-06 — `OTHER THAN` on `SyndicateBook.verify` (N05)

**Deviation.** `verify` always returns false.

**Decision.** Fix with a real URI scan over the syndicate book. Record F-009/HZ-014.

**Status.** Fixed in source; regression not run.

### D-07 — `LATE`/`AFTER` on claims and policy expiry (N11, N12)

**Deviations.** `Policy.openClaim` does not check the loss period/notice window;
`Policy.expire` sets expired without releasing lines; `Slip.expire` does not refund a funded
premium.

**Decision.** Fix `Policy.expire` line release in this pass (F-006/R-006). Record
period/notice (F-010/R-010) and slip refund (F-011/R-011) as open P1s; both need additional
value-move code and tests. `Policy.openClaim` fixing is deferred rather than rushed.

**Status.** F-006 fixed; F-010 and F-011 open.

### D-08 — `UNAUTHORIZED` on `Slip.fundPremium` (N08)

**Deviation.** The arm authenticates any owner but not the insured.

**Decision.** Fix with an explicit insured check. Record F-007/HZ-012.

**Status.** Fixed in source; regression not run.

### D-09 — `AFTER` on line capabilities (N09)

**Deviation.** `Line.credit/pay/release` call the syndicate capability first and update
`lineState` afterwards.

**Decision.** Record F-012/HZ-017. The proposed fix is a single take/repost around the
capability call; not applied because it changes the value-move/rollback shape and needs a
devnet test. Deferred.

**Status.** Open.

### D-10 — `NO/NOT` on books (N15)

**Deviation.** `PolicyBook` and `ClaimBook` are never populated.

**Decision.** Record F-005/HZ-010. Proposed fix R-005 calls the books from the factories;
deferred because it adds a composition call to the already-blocked Policy/Claim creation
path.

**Status.** Open.

### D-11 — `OTHER THAN` on tri-test quality (N03, N07)

**Deviation.** `triTest` checks presence, not numerical probability or cost, and does not
link the fields to evidence.

**Decision.** Record F-017/HZ-021 as a documented design limit; the NAIC primer says so
explicitly. A quality gate is future work, not a silent assumption.

**Status.** Open, documented.

### D-12 — `STALE`/`DUPLICATE` on audit inventory (N15)

**Deviation.** `tests.yaml` listed 3 suites; the harness has 36. The distribution state cell
was declared as `distributionState` while the code uses `distState`.

**Decision.** Sync the test register to 36 suites and correct the catalogue cell. Record
F-016/F-019/HZ-024.

**Status.** Fixed.
