## Purpose

devnet campaign, and decide which P0/P1 findings to fix in this pass. The tabletop covers the
19 nodes in `nodes.yaml` and the interface matrix in `../composition/interfaces.yaml`. The
install-specific pass is in [`worksheet-install-2026-11-05.md`](worksheet-install-2026-11-05.md).

## Decisions and deviations

### D-01 — `LOST` on a state cell in the cornerstone arms (N05, N08, N10, N11, N12)

**Deviation.** The arm takes a state cell, awaits an external component, then takes the same
cell again. The first snapshot is never reposted, so the second receive has no datum.

**Evidence.** `Syndicate@"openLine"` (`10_syndicate.rho:811`/`:868`), `Slip@"bind"`
(`13_slip.rho:427`/`:484`), `Policy@"distribute"` (`17_policy.rho:191`/`:242`),
`Policy@"openClaim"` (`:293`/`:315`), `Policy@"settleClaim"` (`:346`/`:391`,`:433`),
`Claim@"settle"` (`18_claim.rho:390`/`:404`), `Claim@"dispute"` (`:322`/`:361`),
`Distribution@"run"` (`15_distribution.rho:345`/`:360`).

**Decision.** Fix P0 in this pass. Use the original snapshot and repost once after the
awaits; do not add a second take. Record F-001, hazards HZ-001…HZ-005/HZ-025.

**Status.** Fixed in source; scanner `tools/check_take_repost.py` reports zero for the watched
arms. Regression suites remain `not_run`.

### D-02 — `PART OF` a bundle (N01, N05, N09, N11, N12, N15)

**Deviation.** Nine per-object contracts are published with `bundle+{*X}` while `X`'s body
references a state cell or token created outside `X`. The node rejects the bundle.

**Evidence.** Scanner `tools/check_bundle_closedness.py` reports `LineGrant`, `Syndicate`,
`Line`, `Slip`, `Policy`, `Claim`, `Distribution`, `Broker`, `Risk`.

**Decision.** Fix P0 in this pass. The proposed fix is a closed publication/init pattern:
the bundled content must not capture the state cell or the purse/token; maker parameters are
rebound through cfg channels before publication. Record F-002, hazards HZ-006/HZ-007,
improvement R-002.

**Status.** Fixed statically; the bundle scanner reports zero candidates. Install E2 later
completed all 17 terms (`install-recursion-fix.log`) after the RNodeRust codec and the
12_risk/13_slip binding fixes. The behavioural campaign is incomplete: the root suite
passes, the rest are `not_run` or implemented.

### D-03 — `NO/NOT` on global pause (N02)

**Deviation.** `pauseAll` writes `adminState.pausedAll`; no mutating arm consults `isPaused`.

**Decision.** Record F-003/HZ-008. Fix R-003 wires a pause check into the capacity-creating
arms and explicitly exempts settlement, close, expiry and refund. Claims and value-out arms
stay exempt.

**Status.** Fixed; `tools/check_pause_scope.py` enforces the gate matrix. Behavioural
regression remains `not_run`.

### D-04 — `REVERSE`/`STALE` on the fund nonce (N13)

**Deviation.** `SureFund.cover` writes `nonce`; `admin` uses `govNonce`; cover has no
`govNonce` replay check.

**Decision.** Fix: `fundAdmin` rejects `nonce <= govNonce`; cover writes `govNonce`. Record
F-004/HZ-009.

**Status.** Fixed in source; regression not run.

### D-05 — `UNAUTHORIZED` on broker registration (N06)

**Deviation.** `BrokerBook.registerDone` is a public arm accepting an arbitrary id/uri.

**Decision.** Fix: remove the public callback and update `brokerBookState` directly inside
`brokerMake`. Record F-008/HZ-013.

**Status.** Fixed in source; regression not run.

### D-06 — `OTHER THAN` on `SyndicateBook.verify` (N05)

**Deviation.** `verify` always returns false.

**Decision.** Fix with a real URI scan over the syndicate book. Record F-009/HZ-014.

**Status.** Fixed in source; regression not run.

### D-07 — `LATE`/`AFTER` on claims and policy expiry (N11, N12)

**Deviations.** `Policy.openClaim` does not check the loss period/notice window;
`Policy.expire` sets expired without releasing lines; `Slip.expire` does not refund a funded
premium.

**Decision.** Fix `Policy.expire` line release (F-006/R-006), the period/notice check
(F-010/R-010) and the slip refund (F-011/R-011).

**Status.** F-006, F-010 and F-011 are fixed in source; behavioural regressions remain
`not_run`.

### D-08 — `UNAUTHORIZED` on `Slip.fundPremium` (N08)

**Deviation.** The arm authenticates any owner but not the insured.

**Decision.** Fix with an explicit insured check. Record F-007/HZ-012.

**Status.** Fixed in source; regression not run.

### D-09 — `AFTER` on line capabilities (N09)

**Deviation.** `Line.credit/pay/release` call the syndicate capability first and update
`lineState` afterwards.

**Decision.** Record F-012/HZ-017. Fix with a single take/repost around the capability call
and repost on every reply (R-012).

**Status.** Fixed in source; behavioural regression remains `not_run`.

### D-10 — `NO/NOT` on books (N15)

**Deviation.** `PolicyBook` and `ClaimBook` are never populated.

**Decision.** Record F-005/HZ-010. Fix R-005 calls the books from the Policy/Claim
factories.

**Status.** Fixed in source; behavioural regression remains `not_run`.

### D-11 — `OTHER THAN` on tri-test quality (N03, N07)

**Deviation.** `triTest` checks presence, not numerical probability or cost, and does not
link the fields to evidence.

**Decision.** Record F-017/HZ-021 as a documented design limit; the NAIC primer says so
explicitly. A quality gate is future work, not a silent assumption.

**Status.** Open, documented.

### D-12 — `STALE`/`DUPLICATE` on audit inventory (N15)

**Deviation.** `tests.yaml` listed 3 suites; the harness has 36. The distribution state cell
was declared as `distributionState` while the code uses `distState`.

**Decision.** Sync the test register to 36 suites and correct the catalogue cell. Record
F-016/F-019/HZ-024.

**Status.** Fixed.

### D-13 — `LOST` on the RSpace continuation (N16, N18)

**Deviation.** The proposer cannot decode the RSpace continuation of the next block. The
deploy stays Pooled and the chain stops.

**Evidence.** `node.log` contains 94 consecutive `decode continuation failed` errors.
RNodeRust's `models/src/wire.rs` decoded with prost's default recursion limit of 100;
`10_syndicate` normalizes to a deeper Par.

**Decision.** Fix in RNodeRust: enable prost `no-recursion-limit` and add a 130-deep Par
round-trip regression. Record F-022/HZ-028/HZ-032/R-022.

**Status.** Fixed; the rebuilt node installs all 17 terms. The codec regression source is in
the tree, but its execution log is not in this evidence set.

### D-14 — `PART OF` on the Risk bundle (N17)

**Deviation.** The bundled Risk body received the auth reply with a wildcard binder,
`for (@(true, _) <- aCh)`, leaving the bundle open under the wildcard-binder class.

**Decision.** Replace it with the named binder `who`. Record F-023/HZ-030/R-023.

**Status.** Fixed; 12_risk deploys in the 17-term install.

### D-15 — `LOST` on the Slip top-level binding (N17)

**Deviation.** `13_slip.rho` referenced `authIsOwner` without a top-level `new` binding.

**Decision.** Bind `authIsOwner` in the top-level `new` sequence. Record F-024/HZ-031/R-024.

**Status.** Fixed; 13_slip deploys in the 17-term install.

### D-16 — `UNAVAILABLE` on propose mode (N19)

**Deviation.** The harness called manual propose on a node advertising `autopropose:true`
and `manualPropose:false`, racing the node proposer and replacing the internal error with a
Pooled timeout.

**Decision.** Call manual propose only when configured or `RSURE_FORCE_PROPOSE=1`; keep
strict propose for diagnosis. Record F-025/HZ-029/HZ-034/R-025.

**Status.** Fixed; the install-recursion-fix run completed without a harness propose call.

### D-17 — `OTHER THAN` on the r-cash rail (N18)

**Deviation.** The recursion-fixed node accepts the r-sure terms, but the r-cash `51_pool`
term is refused with `parse depth exceeded`; only the account factory installs.

**Decision.** Record HZ-033 as an external-rail residual with the r-cash owner. Do not
describe the r-cash rail as complete, and do not let it invalidate the r-sure install E2.

**Status.** Open (external r-cash).

### D-18 — `STALE` on evidence scope (N19)

**Deviation.** A green install can be read as behavioural coverage while the behavioural
campaign is incomplete: the root suite passes and the rest remain `not_run` or
unimplemented.

**Decision.** Move evidence to `rsure.evidence/v2` with an explicit scope and add the
evidence, RCA and experiment checkers. Record HZ-035.

**Status.** Fixed for this evidence set; the Makefile wiring is owned by the lead.

## Limitations

- No independent facilitator; the roles are an internal simulation.
- The only RCA dynamic evidence is the 17-term install. The behavioural campaign is
  incomplete (root passes, the rest are `not_run` or implemented) and is not covered by
  the tabletop or the install E2.
- The r-cash rail is partial: the account factory installed, but `51_pool` was refused
  with a parser-depth error.
- The successful install run's own node log is not in the evidence directory; the green
  claim rests on the installer's per-term processed output.
- The tabletop is a static reading of the source plus the scanners and the install log; it
  is not proof of correctness.
- The NAIC paper is not a regulatory standard; see the primer's "what this paper does not
  say" section.
